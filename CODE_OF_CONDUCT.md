# Code of Conduct

Be respectful. Assume good intent. Focus on the work.

We welcome contributors regardless of background, identity, or experience.
Harassment, personal attacks, discriminatory language, and bad-faith behaviour
are not tolerated in issues, PRs, discussions, or any project space.

Maintainers may edit, remove, or lock contributions that violate this code and
may block repeat offenders.

Report concerns to the maintainers at security@sera.cx.
