# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Email **security@sera.cx** with a description, reproduction steps, and the
affected component. We aim to acknowledge reports within 3 business days.

## Scope

- `apps/web` and `packages/sera-settlement` in this repository.
- Issues in Sera Protocol itself should be reported through
  [sera.cx](https://sera.cx) security channels, not this repo.

## Supported versions

Only the `main` branch receives security fixes.
