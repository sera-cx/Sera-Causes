# apps/web

The Sera Causes frontend. This is the **forkable** layer: rebrand it, restyle
it, add features, or replace it entirely.

The only rule is that donations are quoted, converted, and settled through
`packages/sera-settlement`, which wraps Sera Protocol. Do not call other swap,
bridge, or conversion services from the frontend for settlement.

Application code is landing incrementally. See the root README for status.
